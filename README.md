# Formação HTML Web Developer

## Desafio 2: Criando um site de uma Clínica

### Objetivo

Este desafio visa criar um site "quase" completo para a Clínica Bom Coração, utilizando todos os conceitos aprendidos no módulo de desenvolvimento web. Os temas abordados incluem formulários, estruturação e formatação de texto, mídias e tabelas, além de outros recursos discutidos nas aulas.
